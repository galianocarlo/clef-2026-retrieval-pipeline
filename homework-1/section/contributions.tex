\section{Group Members Contribution}

All the members contributed based on the capability and comprehension of the topic. Thanks to the different backgrounds (Business Management and Informatics, Statistics and Math) each of the member could contribute in different part of the project.
Below is a summary of the main contributions made by each participant, based on the Git commit history:

\begin{description}
	\item[Carlo Galiano] helped with the initial infrastructure setup, developing the dataset acquisition scripts and the data parsers with language detection capabilities (langdetect library). He engineered the core retrieval pipelines, starting from the multi-field BM25 lexical baseline with tuned hyperparameters and native multilingual analyzers, up to Cross-Encoder semantic re-ranking. Furthermore, he implemented the evaluation framework using the \texttt{ranx} library, developed the automated user-friendly script (\texttt{runner.py}), and contributed to the drafting of the Methodology sections of this paper.
	\item[Alberto Iurlo] On the implementation side, the contribution consisted in: document parsing, text processing, boosting different query fields, bug fixing in the retrieval pipeline, and implementation of the FAISS index and search component for dense retrieval. On the report side, the contribution consist in: helping with methodologies, wrtinging experimental results, conclusions and future works.
	\item[Stefano Riato] prepared the documentation on how to use GIT and Docker for supporting the team in following specific rules and be ready to contribute to the project. Refactoring of indexing and search pipelines of PyLucene to support multi-language queries, PRF integration, and optional FAISS vector-based search. Optimization of document and query parsers through Abstract Base Classes and deque implementations for improved memory efficiency. Development of corpus validation routines and resolution of critical bugs in query parsing and leaderboard scoring. Management of Docker environment, project layout reorganization. Authorship of Introduction, Methodology, Set up and BIM theory sections in the technical report, including diagram creation for each version.

\end{description}
